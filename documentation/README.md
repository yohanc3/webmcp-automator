# Documentation

- [`architecture.md`](architecture.md) explains the state/action model and
  discovery pipeline.
- [`mvp-system-contract.md`](mvp-system-contract.md) defines the ready path,
  executable action format, learning path, and overnight integration cut line.
- [`contracts/system-contract.md`](contracts/system-contract.md) assigns the
  versioned interfaces, invariants, errors, and acceptance tests for every
  ready-path and learn-path component.
- [`parallel-worktrees.md`](parallel-worktrees.md) defines which components must
  move together and the dependency-aware branches, ownership, handoffs, and
  integration waves for parallel implementation.
- [`development.md`](development.md) covers the local workflow, demo, tests, and
  experimental workspace.
- [`privacy.md`](privacy.md) defines the current data boundary and its limits.
- `tests/` contains the repository-path expectations checked by
  `make test-documentation`.
